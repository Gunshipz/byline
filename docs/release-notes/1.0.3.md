# Byline 1.0.3

Released 18 November 2026, for Claude Code.

## What's new

- **`/byline:byline update` updates Byline for you.** Type it, and Byline says what version you're on, runs
  the update, and tells you the version you're on now so you know to restart Claude Code.
- **Byline's own commands are no longer mistaken for writing requests.** Typing `/byline:byline update`,
  `/byline:byline setup`, `/byline:byline flag`, `/byline:byline check` or `/byline:byline review` no longer
  makes Byline treat the message as a draft to check.

## Why

Updating meant quitting Claude Code and typing a command yourself, so most people didn't know when a new
version was out or how to get it.

## How to update

This one last time, update the usual way: quit Claude Code, run `claude plugin update byline@byline`, then
restart. From 1.0.3 on, type `/byline:byline update` instead.

## Known limits

- You still need to restart Claude Code after an update. It keeps running the version it started with.
- A copy of Byline that wasn't installed the usual way can't update itself, and says so.
