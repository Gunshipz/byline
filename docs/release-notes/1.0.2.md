# Byline 1.0.2

Released 18 November 2026, for Claude Code.

## What's new

- **Setup starts by itself.** The first time you send any message after installing, Byline offers to learn
  your voice. Before, you had to ask Claude to set it up. Byline still asks once before it reads anything, and if
  you say no, it won't ask again in that conversation.
- **It needs enough of your writing.** Setup aims for about 4,000 words of your own messages. If it finds fewer
  than 1,000, it tells you how many and asks before saving.
- **It skips messages that look AI-written.** Setup leaves out messages that read like an assistant drafted
  them, such as status reports with headings, bullet lists or bold text, and tells you how many it left out.
- **It protects its own rules.** A flagged phrase is switched off only when it appears in at least two of your own
  messages, not just one.

## Why

Feedback that setup didn't start on its own, and that it once built a profile from 545 words. A test of profiles
built from 500 to 8,000 words of one person's messages, scored by two blind judges across 144 drafts, found no
measurable gain past about 500 words, and slightly worse drafts when AI-drafted messages were left in the sample.

## If you already set up Byline

Nothing changes until you run setup again. If a lot of your writing was drafted with AI, type
`/byline:byline setup` once to rebuild your profile with the new filter. Your old files are backed up first.

## How to update

Quit Claude Code, run `claude plugin update byline@byline`, then restart.

## Known limits

- Byline's voice score can't yet tell a good imitation from a poor one; treat it as a rough check.
- Drafts can still pick up assistant-style structure, such as labels like "New rule:".
