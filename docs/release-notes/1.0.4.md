# Byline 1.0.4

Released 18 November 2026, for Claude Code.

## What's new

- **The docs no longer mention usage tracking.** Byline never counted or sent anything, so the wording
  that said so, and the section it pointed to, are gone. Nothing about how Byline runs has changed.

## Why

Wording cleanup: the docs shouldn't talk about a topic that doesn't apply to this copy.

## How to update

Type `/byline:byline update`, or quit Claude Code, run `claude plugin update byline@byline`, then restart.

## Known limits

- You still need to restart Claude Code after an update. It keeps running the version it started with.
- A copy of Byline that wasn't installed the usual way can't update itself, and says so.
