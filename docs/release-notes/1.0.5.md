# Byline 1.0.5

Released 18 November 2026, for Claude Code.

## What's new

- **A post to a bot chat you've exempted goes through without an ask, even when Byline can't see its text.**
  Before, Byline asked about it anyway.
- **A mail tool you add whose name ends in `email_draft` gets draft handling.** Reading or deleting a draft
  stays silent, and sending a saved draft as it is gets its own ask.
- **`/byline update` works as well as `/byline:byline update`.** Both are no longer mistaken for a request to
  write a message.
- **`/byline:byline update` says so when you're already current.** Before, it had no words for that case.

## Why

Most of this release is behind the scenes: more of Byline's code is shared with its main source, so fixes
arrive here sooner.

## What changes for current users

Nothing you need to do.

## How to update

Type `/byline:byline update`, or quit Claude Code, run `claude plugin update byline@byline`, then restart.

## Known limits

- You still need to restart Claude Code after an update.
- Byline still can't read a field it doesn't know about. When it can't see a send's text, it asks.
